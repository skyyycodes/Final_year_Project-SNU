\chapter{Abstract}
\onehalfspacing

Protecting digital files is difficult because the same work is often shared as images, audio, text, and other media. Most watermarking or steganography tools focus on only one file type at a time. They also usually add only one watermark to one cover file. In real use, however, the same owner may need to add different marks for different users or releases. Using separate tools for each file type becomes inconvenient and inconsistent.

This project presents a simple digital watermarking framework that works with multiple file types through one Java Swing application. The main idea is used in the image module. A user enters a password, and the MD5 hash of that password is used to choose a row and a starting column inside a $256 \times 256$ BMP image. The watermark is then stored in that row using a 3--3--2 split across the RGB channels. A marker is kept at the start of an occupied row so that the program can detect a collision before writing a new watermark. The same application also supports audio, text, and video using a shared payload format with watermark text and timestamp information.

The system was tested on BMP images, WAV audio, plain-text or Markdown files, and short video clips. The results show that the image changes stay visually small, the overwrite check works properly, and the image, audio, and text modules run quickly on normal hardware. This work also highlights some current limitations, such as dependence on lossless media, fixed image size, and the use of basic cryptographic choices like MD5 and XOR. Even with these limits, the framework provides a clear and practical base for further improvement.

\textbf{Keywords:} Digital watermarking, steganography, least-significant-bit (LSB), MD5 hash, row-based embedding, multi-modal, multi-watermark, Java Swing.
